# Jivan Shaili Exhibit Plan

Interactive 3D plan of the 45 x 25 ft Jivan Shaili (Hindu way of life) section for the BAPS Diwali 2026 exhibition, Light Beyond Lamps. Four 11 ft 3 in x 25 ft rooms (Bhasha, Bhusha, Bhojan, Bhajan) with a walkway that switches sides and ends at a centered ghar mandir with two exits, spotlight plan, space check, drawings, shopping list and design and print list.

Live page: https://dillonjivan23.github.io/jivan-shaili-exhibit/

Same format as the Mulyo plan: https://ananpatel21.github.io/mulyo-exhibit/
