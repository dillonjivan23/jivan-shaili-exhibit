# Jivan Shaili Exhibit Plan

Interactive 3D plan of the 60 x 20 ft Jivan Shaili (Hindu way of life) section for the BAPS Diwali 2026 exhibition, Light Beyond Lamps. Four 15 ft rooms (Bhasha, Bhusha, Bhojan, Bhajan) with a walkway that switches sides, spotlight plan, space check, drawings, shopping list and design and print list.

Live page: https://dillonjivan23.github.io/jivan-shaili-exhibit/

Same format as the Mulyo plan: https://ananpatel21.github.io/mulyo-exhibit/
