# Jivan Shaili Exhibit Plan

Interactive 3D plan of the 40 x 20 ft Jivan Shaili (Hindu way of life) section for the BAPS Diwali 2026 exhibition, Light Beyond Lamps. Four equal rooms (Bhasha, Bhusha, Bhojan, Bhajan), spotlight plan, space check, drawings and materials.

Same format as the Mulyo plan: https://ananpatel21.github.io/mulyo-exhibit/
